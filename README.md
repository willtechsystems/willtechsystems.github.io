## Publicação no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `willtechsystems.github.io` ou `portfolio`).
2. Envie todos os arquivos desta pasta para a branch `main`.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, escolha a branch `main` e a pasta `/ (root)`.
4. Salve e aguarde alguns instantes para o site ficar disponível online.

## Tecnologias

- **HTML5 Semântico** com metadados SEO e Open Graph.
- **CSS3 Moderno** (Custom Properties, Bento Grid assimétrico, responsividade mobile-first e micro-interações).
- **JavaScript Vanilla** (zero dependências externas: filtro do portfólio, modal de ampliação dos mockups, navegação ativa e menu responsivo).
